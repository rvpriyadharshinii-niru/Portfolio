The current workspace

From an Agent builder to an Agent workspace.

The newer experience brought more of the Agent lifecycle into one connected workspace — discover, configure, connect tools, test, version and deploy.

Agents
Configured Agents for Home Loans, Personal Loans, Credit Cards, Fraud & Disputes, Deposits and more — each with a model, skill count and status.
Templates
New Agents can start from a browsed template instead of a blank configuration.
Status
Draft and Published states make it clear what’s live versus still in progress.

Create — three starting points for a new Agent.

Configure — instructions, model, memory and knowledge in one place.
